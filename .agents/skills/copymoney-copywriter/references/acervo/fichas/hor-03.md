# hor-03 — Nome com informações de decisão

**Temas.** headline; oferta; criativo

**Fonte.** [hor-journal](https://www.acquisition.com/hubfs/%24100M%20Journal.pdf?_hsmi=270942046) · Offer Headline Formula.

**Princípio na fonte.** O material lista elementos possíveis para o nome de uma oferta e indica que o framework não exige todos ao mesmo tempo.

**Aplicação Copymoney.** Escolha os elementos que tiram uma dúvida real, como público, formato ou duração confirmada.

**Limite da aplicação.** Acumular elementos torna o nome longo. Duração prometida precisa descrever uma condição real.

**Exemplo original.** “Oficina de moagem para café em casa, 90 minutos” informa público, tema e duração em uma linha.
