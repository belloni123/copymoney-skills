# mak-04 — Encontre e ordene benefícios que importam

**Temas.** benefício; argumento; pesquisa; landing

**Fonte.** [mak-benefits](https://www.awai.com/2009/11/benefits-that-sing-and-soar-in-five-simple-steps/) · Passos 3 a 5 e tabela Feature / Why / Benefits / Dimensionalize / Dominant Emotions / Rank.

**Princípio na fonte.** Depois de inventariar características e seus motivos, Makepeace deriva efeitos para o comprador, dá dimensão a cada benefício e os ordena pela importância da melhoria, abrangência do público e intensidade emocional.

**Aplicação Copymoney.** Para uma oferta complexa, faça uma tabela interna: fato do produto → por que existe → o que permite fazer → situação concreta em que importa → evidência → prioridade para este público. Use os itens mais relevantes para escolher a abertura e a sequência da página. Trate emoção atribuída ao público como hipótese até haver linguagem observada.

**Limite da aplicação.** A classificação é julgamento editorial, não medida de desempenho. Não importe números ou resultados imaginados dos exemplos históricos do artigo; verifique cada efeito na oferta atual.

**Exemplo original.** Para software que compara notas recebidas com lançamentos: “lista de divergências” é o recurso; “ver quais registros pedem conferência antes do fechamento” é o uso observável. Uma promessa de horas economizadas exigiria medição própria.
